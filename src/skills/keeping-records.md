---
description: How to file records and how to find one again.
title: Keeping records
---

Write a record when a human asks you to keep something for later. File it under a short topic you
reuse for the same subject, and quote the id the store mints back to the human so they can ask for
that record by id. To find a record again, list by topic or search for a phrase rather than
guessing an id.
